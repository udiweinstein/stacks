# דוח הגשות וציונים

דף אינטרנט שמפיק דוח הגשות וציונים מקובץ CSV.

**לשימוש:** https://udiweinstein.github.io/stacks/

1. פותחים את הקישור.
2. גוררים לדף קובץ CSV עם הנתונים, או לוחצים "בחר קובץ".
3. הדוח נוצר מיד, עם טבלה, סינונים וגרף לאורך זמן.

## פרטיות
הקובץ נקרא ומעובד **בדפדפן בלבד**. הנתונים לא נשלחים לשום שרת, וגם לא ל-GitHub.

## מבנה הקובץ
שורה לכל תלמיד × תרגיל.

- **עמודות נדרשות:** שם תלמיד, תרגול, תרגיל, סטטוס
- **עמודות מומלצות:** כתה, שם משתמש, תרגיל2, תאריך פתיחה, ציון, ציון עבודה עצמית

נתמכים קבצי CSV בקידוד UTF-8 או Windows-1255 (ייצוא רגיל של Excel בעברית), עם פסיק או נקודה-פסיק כמפריד.
